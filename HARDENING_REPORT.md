# Проверка TCPTunnel — 11 октября 2026

Подтверждённые проблемы устранены с сохранением проверки ключей и порядка MLS.

| Проблема | Изменение |
|---|---|
| Неавторизованные соединения занимают лимит участников | Отдельные 24 ожидающих подключения, четыре на источник, ограничение частоты; 64 места для авторизованных участников |
| Долгое TLS-рукопожатие | Срок 15 секунд; ожидание ручного подтверждения имеет отдельный срок |
| Ожидание записи при удержании блокировки комнаты | Под блокировкой пакеты ставятся в упорядоченные очереди; записи и ошибки доставки обрабатываются отдельно |
| Отмена сообщения ждёт предыдущей отправки | Ожидающее сообщение удаляется сразу и освобождает лимит очереди |
| Новый ключ владельца выглядит первым входом в другую комнату | Проверенный ключ закрепляется также за TCP-адресом/портом или Bluetooth-адресом |
| Невидимые символы и похожие ники | Проверка нормализации, разрешённых символов и Unicode confusables; резервирование существующих разрешений сохраняется |
| Управляющие последовательности в ошибках | Очистка текста для обоих режимов консоли; неизвестные ошибки авторизации показываются локализованным сообщением |
| Ошибка MLS скрывает причину отключения | Отдельное локализованное сообщение завершения шифрованного соединения |
| Отказ пакета ключей останавливает весь Hub | Ошибки до изменения MLS отклоняют только соединение; ошибки после начала изменения по-прежнему закрывают комнату |
| Постоянное UPnP-правило | Продлеваемое правило на час |
| Повышение прав и изменение Bluetooth-политики | Автоматическое повышение и запись системной политики удалены; приложение показывает причину отказа |
| Перехват ники владельца в обычном Hub | Владелец подключается внутренним каналом; внешний клиент не может занять его ник |
| QuickEdit блокирует классическую консоль | QuickEdit отключается при запуске |
| Безопасность запуска и поддержка платформы | .NET 10, ограниченный поиск DLL, CFG/CET для lite, контрольные суммы сборок |
| Исходники проверок исключены из Git | Исключаются только результаты; добавлен Windows CI с криптографическими, регрессионными и публикационными проверками |

Новая ABI 5 исключает использование старой DLL с изменённой классификацией ошибок MLS.
Данные Unicode закреплены контрольной суммой и исключены из преобразования окончаний строк Git.
Старые профили с запрещёнными символами можно загрузить и переименовать в новый свободный
ник, сохранив ключ. Изменение ника требует отдельного разрешения в комнате.

Проверки:

- 101 проверка приложения: успешно, без предупреждений компиляции.
- 9 Rust-проверок и 16 проверок криптографической обёртки: успешно.
- RustSec и NuGet: известных уязвимостей в проверенных зависимостях не обнаружено.
- 14 локальных сценариев ввода изображений/GIF в чат: успешно, включая графический режим,
  пробелы, Unicode, апострофы, PowerShell-формат и отклонение повреждённого файла.
- Готовые lite и self-contained EXE: E2E-проверки успешно; self-contained самопроверка
  и нагрузочная проверка успешно.
- Bluetooth на этом компьютере: запуск, повторное объявление и остановка успешно.

Lite: 31 221 760 байт (29,78 МиБ), требует .NET 10 Runtime x64.
Self-contained: 45 472 927 байт (43,37 МиБ), включает среду выполнения.
Рядом с каждым EXE сохраняется файл SHA-256; сравнивать его следует с доверенным источником.

Проверки не заменяют независимый аудит. Передача по реальному Bluetooth между двумя
компьютерами не проверена: второй компьютер недоступен. Владелец Hub остаётся видимым
участником группы и читает чат. Компрометация конечной точки раскрывает доступные ей
данные. Сохранение диалогов и отдельный слепой relay остаются будущими функциями.
Исполняемые файлы не подписаны Authenticode. CI подготовлен и его команды проверены
локально; запуск на GitHub требует отправки коммита, которая не выполнялась.
